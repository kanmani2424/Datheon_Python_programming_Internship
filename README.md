# Python Programming Internship – Projects

This repository contains four Python projects completed as part of my Python Programming Internship.

## Tasks

### Task 1 – Hangman Game
A terminal-based word guessing game. The player guesses letters to uncover a hidden word.

**Technology:** Python  
**Project folder:** `Task1_Hangman/`

### Task 2 – Stock Portfolio Tracker
A Python project for tracking stock portfolio information.

**Technology:** Python  
**Project folder:** `Task2_Stock_Tracker/`

### Task 3 – Automated File Organizer & Cleanup Utility
A desktop file-organizing utility that scans a directory, identifies files by extension, creates category folders, and moves files into the appropriate folders. It handles file-operation errors and reports a summary of its work.

**Technologies:** Python, `os`, `shutil`, `pathlib`  
**Main file:** `organizer.py`  
**Project folder:** `Task3_File_Organizer/`

### Task 4 – Rule-Based Interactive Terminal Assistant / Chatbot
A terminal chatbot that recognizes greetings and FAQ-related questions using keywords and regular expressions. It loads FAQ content from a JSON file, responds to recognized questions, provides a fallback for unrecognized input, and supports commands such as `bye`, `exit`, and `quit`.

**Technologies:** Python, `re`, `json`  
**Main files:** `chatbot.py`, `sample_faq.json`  
**Project folder:** `Task4_Chatbot/`

## How to Run

1. Install Python 3.
2. Open the required task folder in a terminal or command prompt.
3. Run that task's Python script. For example:

```bash
python hangman.py
python stock_tracker.py
python organizer.py
python chatbot.py
```

For Task 4, keep `sample_faq.json` in the same folder as `chatbot.py`.
