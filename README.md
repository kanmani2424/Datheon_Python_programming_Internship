# Hangman Word Game

**Author:** Kanmani S

## Project Description
Hangman is a simple word-guessing game developed using Python. The computer randomly selects a word from a text file, and the player must guess the word one letter at a time.

The player has a limited number of attempts to guess the correct word. ASCII art is displayed to represent the Hangman game.

## Technologies Used
- Python
- Random Module
- Pathlib Module
- Text File Handling

## Features
- Random word selection.
- Displays hidden words using underscores.
- Accepts one alphabet letter at a time.
- Validates user input.
- Prevents repeated guesses.
- Displays correct and wrong guesses.
- Shows remaining attempts.
- Displays win or game-over messages.

## Project Files
- `Hangman.py` – Main Python game program.
- `google-10000-english-no-swears.txt` – Word list used to select random words.

## How to Run the Project

1. Install Python on your computer.
2. Keep both files in the same folder.
3. Open the terminal in the project folder.
4. Run the following command:

```bash
python Hangman.py
```

## How to Play
1. Run the Python program.
2. A random word will be selected.
3. Enter one alphabet letter at a time.
4. Guess the hidden word before using all attempts.
5. Win the game by guessing all the letters correctly.

## Output
The game displays the hidden word, Hangman ASCII art, remaining attempts, and the final winning or losing message.

## Conclusion
The Hangman Word Game is a beginner-friendly Python project that demonstrates random word selection, loops, conditional statements, functions, sets, and file handling.
